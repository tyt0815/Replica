# 개발 상태

## 시작점

저장소 초기 구성 단계다. YMusic 기준 커밋은 `62984b6def759dc3e0a7b6c1b820f76dc949d38d`이다. 기존 Replica Music에서 참고하던 리비전을 선택했다. 이후 정확한 버전은 상위 저장소에 기록된 서브모듈 포인터를 따른다.

## 다음 작업

1. Android용 최소 Flutter 앱에서 YMusic 검색 결과 한 건을 오디오로 재생한다. 연결에 필요한 모듈과 실제 빌드 명령을 기록한다.
2. 같은 항목을 영상으로 열어 화면 출력, 재생 위치, 오디오 포커스 전환을 기기에서 확인한다.
3. 앱을 재설치하지 않고 JS 번들이 교체되는지 확인한다. 호환되지 않는 번들을 받았을 때 복구 경로도 확인한다.

Flutter 앱, 플랫폼 연결, 빌드 및 실기기 검증은 아직 진행하지 않았다.
