## 변경 사항

- 재생목록에서 곡을 옮길 때 YouTube에 잘못된 항목 ID를 보내던 오류를 수정했습니다.
- 재생 기록은 기기마다 하나의 `History.기기이름.rm` 목록을 사용합니다. 기기별 목록이 없으면 기존 `History.rm` 하나를 이름만 바꿔 이어서 사용합니다. 이미 생긴 중복 목록은 보존합니다.
- 다시 들은 곡은 기록 맨 앞으로 이동하며 최근 100곡을 유지합니다.

## 검증 범위

정적 분석, 위젯 테스트 14개, 곡 항목 ID 회귀 테스트를 통과했습니다. Android 에뮬레이터에서 0.4.1 위에 업데이트하고 앱을 실행했습니다. 실제 YouTube 계정의 기기 간 동기화와 Fold8 실기기 동작은 미검증입니다.
