### 변경 사항

- Replica Music의 Flutter UI와 Rust 코어 기능을 통합했습니다.
  - 보관함, `.rm` 재생목록 YouTube 동기화, 검색, 다운로드 우선 로컬 재생(`just_audio`, `audio_service`), Now Playing 시트, 기기별 재생 기록, 오류 로그 내보내기, 테마 전환(시스템·라이트·다크), Fold8 4가지 화면 레이아웃을 지원합니다.
- 앱 시작 시 자동 업데이트 확인을 제거하고 설정의 **업데이트 확인**에서 수동으로 확인하도록 변경했습니다.
- 앱 아이콘을 포인트 색상(`#FF0035`) 배경의 새 심볼로 교체했습니다.

### 설치 안내 및 알려진 제약

- 0.2.0과 같은 배포 키로 서명했습니다. 기존 0.2.0 설치본 위에 바로 업데이트할 수 있습니다.
- Android 9(API 28) 이상, ARM64 및 x86_64 기기를 지원합니다.
- ARM64 실기기 및 Fold8 실기기 화면 전환 검증은 남아 있습니다.
- 영상 전용 화면과 YMusic 엔진 OTA 통합은 후속 개발 범위입니다.
