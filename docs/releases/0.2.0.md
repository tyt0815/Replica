### 변경 사항

- 앱 시작 시 새 버전을 확인합니다. 설정의 **앱 업데이트 확인**에서도 직접 확인할 수 있습니다.
- 다운로드를 선택하면 APK의 크기와 SHA-256을 검사하고 Android 설치 화면을 엽니다.
- ARM64와 x86_64를 지원합니다. 검색 결과는 YMusic 파서로 읽고 영상은 YouTube 임베디드 플레이어로 재생합니다.

### 설치 안내

첫 설치에는 첨부된 APK를 사용하세요. 0.1.0 로컬 시험판은 서명이 달라 덮어쓸 수 없습니다. 기존 앱을 삭제하면 해당 앱 데이터도 삭제됩니다. 0.2.0부터 같은 배포 키로 업데이트합니다.

YMusic 네이티브 재생과 엔진 OTA는 개발 중입니다.
