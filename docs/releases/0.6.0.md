### 변경 사항

- 검색 결과를 누르면 Android에서 YouTube 영상을 스트리밍합니다. 화면 상단에 영상을 표시하고 그 아래에 제목, 채널명, **닫기**, **YouTube에서 열기**를 배치했습니다. 영상 재생은 음악 파일을 저장하거나 음악 기록에 곡을 추가하지 않습니다.
- 보관함에서 음악 기록과 음악 재생목록을 가로로 넘겨볼 수 있습니다. 제목 오른쪽의 세로 점 메뉴에서 항목을 관리하고, **더보기**에서 전체 항목을 세로 목록으로 볼 수 있습니다. 카드와 목록에서 기기 정보와 곡 수 표시를 제거했습니다.
- 기록·재생목록의 전체 목록과 상세 화면은 왼쪽에서 들어옵니다. 뒤로 가면 왼쪽으로 나갑니다.
- 분할 화면은 재생창을 기본으로 왼쪽에 표시합니다. 본문을 가로로 밀면 위치를 교체하고, 하단 탭 독을 밀면 단일 화면과 분할 화면 모두 탭을 전환합니다.
- 음악 기록 동기화에서 곡 순서를 확인하는 방식을 수정하고 깨진 한국어 오류 문구를 복구했습니다.
- 곡 선택 모드에서 하단 왼쪽 원형 버튼으로 전체 선택할 수 있습니다.

### 설치 안내 및 알려진 제약

- Android 9(API 28) 이상, ARM64 및 x86_64 기기를 지원합니다. 기존 배포 키를 사용해 서명했습니다.
- YouTube가 앱 안의 재생을 제한하는 영상은 영상 화면의 **YouTube에서 열기**로 열 수 있습니다.
- Fold8 실기기와 실제 YouTube 계정의 음악 기록 동기화 검증은 남아 있습니다.
