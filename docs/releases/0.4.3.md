## 변경 사항

- 저장된 음원을 처음 눌렀을 때 오디오 포커스가 충돌해 일시정지되던 문제를 수정했습니다.
- 저장되지 않은 곡을 누르면 현재 재생을 멈춥니다. 다운로드를 마치면 선택한 곡을 자동으로 재생합니다.
- 재생목록의 더보기 메뉴에서 편집을 열 수 있습니다. 편집 중에는 하단의 전체 선택과 삭제를 사용하고 상단의 체크 버튼으로 저장합니다. 저장된 곡에도 같은 편집 화면을 적용했습니다. 일반 재생목록의 곡은 드래그로 순서를 바꿀 수 있습니다.
- 재생목록 동기화 완료와 전송 대기 알림을 제거했습니다.
## 검증 범위

정적 분석과 위젯 테스트 14개를 통과했습니다. Android 에뮬레이터의 Release APK에서 저장한 곡 두 개의 첫 탭 재생, 일시정지, 선택 삭제를 확인했습니다. YouTube 다운로드 후 자동 재생은 위젯 테스트에서 검증했습니다. 실제 YouTube 음원 다운로드와 Fold8 실기기 동작은 미검증입니다.
