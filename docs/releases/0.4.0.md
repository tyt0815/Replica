### 변경 사항

- `ReplicaMusic`에서 가져온 Rust 코어(`crates/replica-music-core`)와 Flutter 내부 네트워크·재생 의존성(`HttpClient`, `just_audio`, `ffi`)을 모두 제거했습니다.
- Flutter는 UI와 `MethodChannel` 브리지 계층만 담당하도록 정리했습니다.
- **`vendor/YMusicV4`** 모듈(`:dynamic-engine`, `:engine-js`, `:quickjs`, `:yt-media`, `:download`, `:player`, `:kmpHttp:core`)을 수정 없이 Gradle composite build로 연결했습니다.
- 추후 Windows 데스크톱에서도 재사용할 수 있도록 공통 Kotlin 백엔드(`:replica-backend`)와 얇은 Android 어댑터(`MainActivity`, `YMusicPlayerBridge`, `WebViewCookieJar`)로 계층을 분리했습니다.
- YMusic 코어가 직접 제공하지 않는 `.rm` 재생목록 이름 변경·삭제·빈 목록 생성·동기화, GitHub Releases 앱 업데이트, 오류 로그 저장은 상위 저장소의 Kotlin 백엔드에서 YMusic HTTP 클라이언트와 쿠키를 재사용해 보완했습니다.
- Release APK 크기가 45.8MB에서 19.9MB로 줄었습니다.

### 설치 안내 및 알려진 제약

- 0.2.0 / 0.3.0과 같은 배포 키로 서명했습니다. 기존 설치본 위에 바로 업데이트할 수 있습니다.
- Android 9(API 28) 이상, ARM64 및 x86_64 기기를 지원합니다.
- ARM64 실기기 및 Fold8 실기기 화면 전환 검증은 남아 있습니다.
- FFmpeg 사전 빌드(`ffmpeg-build`) 없이 빌드되므로 로컬 재생은 Media3 `ExoPlayer` 폴백을 사용합니다.
